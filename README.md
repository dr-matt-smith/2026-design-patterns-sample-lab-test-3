# Design Patterns 2026 - sample lab test 3 (State pattern)

Two sample lab tests on the State pattern. Each folder is a separate Deno + TypeScript project.

- [`lab_test_3_SAMPLE_1_traffic_lights`](lab_test_3_SAMPLE_1_traffic_lights/README.md) - a 3-state traffic light (RED → GREEN → AMBER → RED). Start here.
- [`lab_test_3_SAMPLE_2_gumball`](lab_test_3_SAMPLE_2_gumball/README.md) - the Head First gumball machine.

Run a sample's menu from inside its folder:

```bash
deno run src/main.ts
```
